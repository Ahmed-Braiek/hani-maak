# Code of Conduct

Hani Maak contributors are expected to collaborate professionally, respectfully and in good faith.

We welcome constructive technical disagreement, careful review and evidence-based criticism. Harassment, discrimination, intimidation, personal attacks, doxxing and deliberate disclosure of confidential or patient information are not acceptable.

For a health-tech project, responsible collaboration also means:

- never using real patient information in examples, issues or test fixtures without an approved governance process;
- not weakening safety or access-control boundaries for convenience;
- reporting security vulnerabilities privately;
- distinguishing implemented behavior from planned work and measured results from assumptions.

Project maintainers may edit, remove or reject contributions that violate these expectations and may restrict participation when necessary to protect contributors, users or the project.

Concerns about contributor conduct should be raised privately with the repository maintainer whenever possible.

# Support

Hani Maak separates engineering support from patient/medical support.

## Developers and contributors

Use GitHub issue forms for reproducible bugs and feature requests that do not contain sensitive information. Include the affected role, module, browser/device and relevant sanitized logs.

## Heni Chat / Voice problems

Use the dedicated Heni issue form for language behavior, hallucination/safety concerns, latency, transcription, TTS or model-version problems. Use synthetic examples only.

## Security vulnerabilities

Do **not** file a public issue. Follow [`SECURITY.md`](SECURITY.md) and contact the maintainer privately.

## Product or healthcare support

This repository is not a medical-help channel. Do not post symptoms, treatment questions, medical records or patient identifiers here. Hani Maak's clinical boundary requires medical decisions to remain with qualified healthcare professionals and the relevant provider.
